# Gestão 3D

App de celular para gerir o negócio de impressão 3D: custo real de cada peça, estoque, vendas por canal, anúncios, filamentos e lucro líquido.

**Abrir:** https://fodastico01.github.io/gestao-3d/

## Como instalar no Android
1. Abra o link acima no Chrome.
2. Menu (⋮) › **Adicionar à tela inicial** / **Instalar app**.
3. Depois da primeira abertura, funciona sem internet.

## Onde ficam os dados
Somente no navegador do celular (localStorage). Nada de vendas ou custos vai para o GitHub.
Use **Mais › Exportar / Importar** para fazer backup em JSON (guarde no Google Drive) e exportar CSV para planilhas.

## Arquivos
- `index.html` – o app inteiro (HTML + CSS + JavaScript, sem dependências)
- `manifest.webmanifest`, `sw.js` – instalação e modo offline
- `icon-192.png`, `icon-512.png` – ícones
